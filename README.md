# RREF Calculator – Infinite Dimensional

A browser-based calculator that reduces matrices of any size to **Reduced Row Echelon Form (RREF)** and solves systems of linear equations.

**Live demo:** https://jfcortes1202.github.io/RREF-Calculator-Infinite-Dimensional/

## Features

- Reduce matrices of any size to RREF
- Solve systems of linear equations
- Runs entirely in the browser: a single `index.html` with nothing to install

## Usage

Open the live demo, or download `index.html` and open it in any modern browser.
